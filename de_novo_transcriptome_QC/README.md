# de-novo-transcriptome-QC
Pipeline to compute several statistics on the quality of a de novo transcriptome.
The pipeline is based on snakemake, the config.yaml must be set up first before launching the pipeline.
A toy dataset is available in the `data` folder to test the installation.

The `transcriptome_QC.yml` is a conda envorionement containing all needed packages to make the pipeline works.
